# ゲーム版の確認

2026-10-08日本時間に確認した。

- 実ゲームの起動ログ：RimWorld 1.6.4871 rev591。
- ローカルSteam appmanifest：app 294100、installed build 23969874、更新待ちのTargetBuildIDは0。ローカル記録だけでSteam側の配信最新buildまで確定したとは扱わない。
- [Ludeon公式の更新記事](https://ludeon.com/blog/2026/06/update-1-6-4850-released/)と[公式Steam告知一覧](https://store.steampowered.com/news/posts/?appids=294100&feed=steam_community_announcements)を確認。公式記事で確認できたゲーム更新は2026-06-08の1.6.4850であり、手元の1.6.4871より古い。告知記事の新旧だけでは小規模更新やhotfixを含む最新buildを断定できない。

継承圏の対応宣言は1.6、実ゲーム検証は1.6.4871 rev591を基準とする。Steamの現在の公開branch／配信buildとの直接照合は未完了。次のゲーム更新が判明した場合は保存・実物所有・DLC APIに関係する差分を確認し、該当試験を再実行する。

2026-10-11再確認: 公式Ludeon記事とSteam公式告知一覧の読取で、1.6.4850の2026-06-08告知を再確認した。ローカルappmanifestはbuild23969874/TargetBuildID0のまま。これらを現在のSteam公開branchの直接照合と同一視せず、1.6.4871 rev591実検証という限定を維持。配布17のREADMEとReleaseNotesもこの限定を明記している。ユーザーの設定・Steam branch・ゲーム本体は変更していない。
