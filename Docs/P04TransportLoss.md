## 操作と効果

出発後の保留便へ「照合し直す」と「配送品の不足を確認」を追加した。照合は元の住民、キャラバンまたは目的地マップ、元の積荷ID・Def・確定数量を再確認する。条件が一致すれば同じ便を輸送中へ戻す。すでに元の住民と積荷が目的地へ入っている場合は、物理移動をせず到着記録だけを確定する。不足を黙って受け入れる操作ではない。

不足確認の画面は、前回確定した配送数量、元の積荷の現在残量、今回確定する不足を表示する。「不足を確定して続行」で、その数量を記録し、残っている物資で納品を続けられる。「保留を続ける」または画面を閉じる操作では記録を変えない。数量確認と確定はゲーム内の操作で行い、制作中のエージェントへの承認要求を意味しない。

確認後に残量、確定記録の親、または住民の所在区分が変わった場合は、古い確認内容を拒否する。全ての元住民が生存し、プレイヤー所属で、元のキャラバンまたは目的地に揃っていることが必要。捕獲・死亡・行方不明・別マップへの移動は不足受け入れだけでは解消できない。

## 保存契約

元の輸送依頼と貨物ID、数量、旅用指定は変更しない。PhysicalTransportRecordへlossCountとlossesを追加し、旧保存では0件として読む。各PhysicalLossRecordは操作原因、Coreの確定証、前回の確定証、積荷の順序に対応する残量配列を持つ。配送品は前回数量以下へ減る場合のみ受け入れ、少なくとも一つが減る必要がある。旅用食料の要求数量はこの配列では減らさず、従来の消費許容を使う。

Coreのleaseとcreate操作が、便ID、元キャラバンID、貨物IDと順序、親の確定証、操作原因、残量を結び付ける。受け入れは同期した一つのゲームスレッド処理で、現物を移動・生成しない。同じ確認内容の繰り返しは同じ確定証IDを返す。追加の損失は別の確認と確定証を必要とする。到着記録は最後の不足確定証も参照して要求を固定する。

読み込み前の検査で、件数、数量の単調減少、旅用数量の維持、親の順序、Coreの確定済み操作とleaseの一致を確認する。lossesを削除してCore証を残す保存も、孤立したColony資産として拒否する。最後の確定証のローカル参照だけが欠け、Coreが同じ内容を確定済みで、便が保留状態の場合は、既存IDを復元する。新しい確定証や物資を作らず、元の所在と数量を観察して状態を復旧する。

配送残量0も明示的に受け入れられる。納品時に失われた積荷を再生成しない。受け入れ後に元数量へ戻す操作は未実装で、前回確定量を上回る貨物を認めない。通常のThing負荷IDと数値IDを使って、同じ元個体のDefが変わった場合を検出する。独自の負荷ID形式を持つ他MODの貨物は、安全に照合できない場合は不足受け入れを拒否する。

## 試験手順と限界

隔離したRimWorld 1.6.4871 rev591で基本ゲームとRoyalty / Ideology / Biotech / Odysseyを使用する。LossAccept → LossCheckpoint → LossLoad → LossFinal、LossZero → LossZeroFinal、LossDeliveredをBuild/RunSmoke.ps1へ追加した。LossAmount / LossMissing / LossParentはPhysicalFaultLoadの改変fixture。LossRenderEnglish / LossRenderJapaneseは元ゲームで不足確認画面を開く。

LossAcceptは旧0.4.2の保留保存を起点に、古い確認の拒否、異なるDefと他国所属住民の拒否、30→28→27の二段階の不足確定、反復、確定済み残量以上への増加拒否、元依頼と物理IDの保持を調べる。LossCheckpointは二つ目のローカル確定証参照を欠かせた保存から、同じCore IDと件数を復元する。LossLoad / LossFinalは標準経路で到達し、元貨物27個と不足3個の履歴を保持する。経路更新だけを加速する試験であり、通常の長期旅行ではない。

LossZeroは元配送鋼鉄の残量0を受け入れ、到着と再読込で失われた30個を補充しないことを調べる。LossDeliveredは元の住民が既に目的地へ入った場合、二度目の転送をせず不足と到着を記録する。描画の確認と共通コントローラーの試験は、実マウスのクリック試験とは区別する。既存日本語の36／28件の公式DefInjectionエラーは0.4.2の既知リストと照合する。

最終結果とDLLの一致はEvidence/P04Lossへ保存する。動物、荷重、捕獲者の救出、別キャラバンへの移し替え、受け入れた損失の撤回、委任保管・生産・維持費、通常の長時間旅行、長期性能、独立レビューは未完了。
