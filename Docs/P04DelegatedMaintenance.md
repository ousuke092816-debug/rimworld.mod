# P04 委任住民の維持費自動精算（0.4.11）

0.4.10の元Pawn保管と個人inventory食料控除を基礎に、明示的に開始した維持費だけを毎日事前払いする。普通のPawn tick、生物年齢、need、健康、技能、生産は引き続き凍結する。これだけで委任生活の完成とは扱わない。Core保存版7／Colony保存版1の追加項目。旧版へ戻す操作は新しい証明がある場合に拒否される。

## 時計と保存

- 元の入庫証ごとに一つの計画を登録する。元個体／都市／入庫証／開始日は開始controlのCore leaseで固定する。
- 開始／停止／再開／保留は前のcontrol証への鎖を含めて個別のCore leaseで固定する。制御証は都市のtransaction lockと独立するためCore参照先を持たず、完全な対象識別子をhashに含む。
- 次回日は最後の開始・再開日と、同じ元入庫の確定済みCore食料証から導出する。XML内の任意の時計を権威にしない。手動で同日分を払っていた場合も採用し、追加請求しない。
- 当日の新しい食料証だけを作る。次回日が現在日より過去ならDayGap保留にする。明示再開は飛ばした期間を無請求の凍結期間として承認し、現在日から再開する。過去日の食品を新規消費しない。
- 入庫場所が変わった同日に別入庫の既払証がある場合は開始を拒否し、翌日まで待つ。元入庫が終了した計画は履歴として残し、再入庫へ付け替えない。
- 食料不足・途中の食料操作・元隊列喪失・特殊資源・食品貨物予約は保留。自動再試行を繰り返さず、明示再開または途中証の独立復旧を使う。
- 停止は将来の請求だけを止める。途中のCore食料証を消さず、停止したままその証を復旧できる。既存の計画は新規開始設定を無効にしても継続する。

## 通常画面

元住民・動物、位置付き拠点、個人別の食料栄養と日額、開始日／最終支払日／次回日、保留理由、途中証の回復を表示する。位置のない旧拠点と元隊列の喪失を明示する。新規開始設定と日英文言を追加。元個体の入出庫自体はまだ開発用接続であり、通常の多都市運営完成ではない。
