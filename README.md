# 継承圏（Inheritance）— 開発中のRimWorld MODシリーズ

六文化の種族・建築・武器、国家と都市、外交、定住と複数拠点運営、遺伝子改良を目指す開発中のプロジェクトです。仕様にある機能すべてが実装済みではありません。

2026年10月23日時点の製品版管理番号は **0.4.17**、開発・互換試験の固定基準は **RimWorld 1.7.4982 rev1280** です。1.7への正式対応と試作コードの製品統合は未完了です。現在の状況は [Docs/CurrentStatus.md](Docs/CurrentStatus.md)、工程は [Docs/OverallProgress.md](Docs/OverallProgress.md) を参照してください。

- `Source/`：Core・Colony・WorldのC#ソース
- `Mods/`：MOD定義と翻訳
- `Build/`：ビルド・パッケージ作成用スクリプト
- `Tests/`：開発用の試験コード
- `Docs/`：設計・進捗・検証範囲の説明
- `Art/`：外観案と制作途中の画像素材

ゲーム本体、セーブ、ビルド済みDLL、過去の試験証拠、一時作業環境はこのリポジトリに含めません。ビルドには別途RimWorld本体が必要です。文書に登場する隔離試験用の `work/` はローカル環境側で管理しているため、ここには含まれません。

以下は以前の配布試作版についての説明です。最新の実装・検証状態と区別してください。

# 継承圏 — 0.4.16

2026年10月9日。食品の移管準備と抽象・実物輸送が重なった際の事前拒否・自動待機・確定証の保存復旧を補強しました。同じ最終製品で39実ゲーム試験（基本19／対象4DLCあり20）が成功し、実行環境の製品ファイルとSHA256が一致しました。間接予約の公開Core APIも、準備中は結果IDや途中証を作る前に拒否します。Core9／Colony1／World1／protocol2を維持しています。0.4.15の以下の結果は前版の記録です。

2026年10月9日。食品の移管準備・解除証とCore保存版9への移行を追加し、同じ最終製品DLLで63実ゲーム試験（基本31／四DLC32）が成功しました。人間・動物、準備後の通常消費、途中証の保存再開、不正保存の拒否、旧機能の回帰を確認しています。準備は元食品を確保・移動する物理予約ではなく、競合するMOD内操作を待機・拒否する保存責任です。実物食品の移管と通常画面への公開は後続です。
以下の通常画面は0.4.13から引き継いだ機能です。保管個体ごとに元隊列の食品候補を読む専用画面を追加し、同じ最終製品DLLで36試験と日英9画像を確認しています。通常画面から委任地点を登録し、元キャラバンの住民・動物を装備と所持品ごと保管して、同じ元キャラバンへ返せます。食品候補画面は持主・数量・食べ手別の栄養・日需要・競合理由を表示します。P04全体は制作途中で、食品移管と委任住民の生活・生産・健康更新はまだ実装していません。

## 含まれるもの

- **Core**：恒久ID・所有台帳・途中操作の復旧、元住民・動物の深い保存、個人食料の日別支払証を管理します。人物や所持品を名前から再生成しません。
- **Colony**：直接拠点と委任地点の一覧、実物輸送の予約・取消・出発・標準経路・到着、旅用食料・動物・重量、不足の確認と残量納品を提供します。
- **委任管理**：停止中の元隊列の現在地を登録し、住民・動物を個別に入出庫します。最後の適格な人間護衛を隊列に残し、輸送予約や未完了操作との競合を防ぎます。設定を無効にしても既存の返還・途中操作の再開は利用できます。
- **食料維持費**：委任中の個人所持品にある対応食品から、明示開始した日次支払を自動精算します。不足や日付飛びで保留し、現在日から明示再開できます。途中の食品処理は同じ記録から復旧します。
- **食品候補**：元隊列の現物食品と補給を妨げる条件を個体ごとに読み取ります。候補確認による移管・予約・食品消費はありません。
- **World**：簡略台帳上の六国家、地域分け、各国L1〜L4の計24都市と6首都、管理国・収入・遷都を保存します。訪問できる都市マップ、外交・戦争AI、文化の種族・建築・武器は後続工程です。

保管中は通常の空腹・生物年齢・健康・技能・生産を更新しません。暦年齢は世界時計とともに進みます。食料維持費の支払いは会計であり、日常生活の再現ではありません。使用済み食品は監査用の原物として別容器に保持し、処分・集約はまだ行いません。

共有倉庫、通常の食品補給、別隊列への受け渡し、委任生活・治療・生産、長距離遠征の検証は残っています。遠隔の抽象在庫をその場の製造材料として使いません。大規模な遺伝子庫・六文化の内容・還元群・旧敵の置換も今後の工程です。

## 導入と操作

1. 検証済みの `Inheritance-0.4.16-prototype.zip` を展開し、使うMODフォルダーをRimWorldの `Mods` へコピーします。
2. Coreを先に有効にします。ColonyとWorldはそれぞれ任意に追加できます。同じ配布版の組み合わせを使い、開発用TestsのMODは通常プレイへ導入しません。
3. 新しいテスト世界で「オプション → MOD設定 → 継承圏 — Colony」から現在のプレイヤー拠点を登録し、連絡局の一覧を開きます。実物輸送・原拠点の凍結保管・委任管理・食料維持費の設定は個別で、初期値は無効です。
4. 実物輸送は二つ以上の直接拠点を登録してから有効にし、住民・動物・荷物と旅用食料を選んで予約、出発します。重量と食料の目安を確認してください。配送用食品もゲーム本体の通常摂取で消費されることがあります。
5. 不足した便は「配送品の不足を確認」から残量を確認し、「不足を確定して続行」で同じ便を進めます。住民・動物の行方不明や死亡は物資不足として補いません。
6. 原拠点の凍結保管は、同じ読み込み中の元マップへ戻す操作です。復帰用の空きマスを確保してください。設定offでも保管済み個体を戻せます。
7. 委任管理画面では、地表で停止中のプレイヤー元キャラバンを選び、空いている現在地に名前を付けて登録します。「入庫する」「元隊列へ戻す」で操作し、途中操作があれば下の一覧から再試行します。新地点登録では既存のマップ・集落・登録地点を避けます。保管中の個体の「食品候補の確認」で専用画面を開けます。
8. 「食料維持費を開く」で保管住民を選び、支払を開始します。不足は個人の食品を確認し、日付飛びは凍結された未払期間を認めて現在日から明示再開します。停止していても途中支払いの復旧は利用できます。
9. 六国家の台帳を試す場合は、新規世界生成前にWorldの追加設定を有効にします。既存世界へ後付けで六国家を生成しません。

Harmonyと追加DLCは必須ではありません。登録済みColonyデータにはColony、六国家モードにはWorldが必要です。必須パック欠落や不整合な保存は理由を記録してメニューへ戻します。制作版は新規テスト世界向けです。

今後の六文化の種族パックは、ユーザー指定によりHumanoid Alien Races（HAR）を前提とします。大型種族もHARで表現し、追加遺伝子はBiotechと組み合わせます。現在のCore・World・Colonyには種族パックもHARへの依存も入っておらず、Core＋四DLC＋HARの初期化を別構成で確認しました。六種族の実装とColony／WorldのHAR併用試験は後続です。

## 確認範囲

試験ゲームは **RimWorld 1.6.4871 rev591**。DLCなしと、Royalty・Ideology・Biotech・Odysseyの構成で分けて確認します。Anomalyは不要です。Steam安定ブランチの最新配信rev照合は未実施で、[GameVersionCheck](Docs/GameVersionCheck.md)に確認根拠を記録しています。

0.4.14は37試験（新規24／既存13回帰）を確認し、[検証記録](Docs/Evidence/P04DelegatedSupplyIntents/README.md)の39ファイルを保存しました。新しい画面画像は今回検証していません。0.4.13では36試験（基本19／四DLC17）と日英9画面を確認しました。候補照会・描画の新規10、影響範囲の既存25回帰、Worldを含む三モジュールの保存再読込1です。[保存した検証記録](Docs/Evidence/P04DelegatedSupplyPreview/README.md)は47ファイル。配布ZIPの全項目を元ファイルとSHA256照合します。0.4.12の243試験と12画像は[過去版の証拠](Docs/Evidence/P04DelegatedManagement/README.md)に保持し、別DLLの試験を今回の件数へ合算しません。

描画は3440×1440の実ゲーム画像を主担当が目視しました。コントローラーを通した命令試験と描画試験を行っており、実マウスの全操作、最小解像度、長期・多数拠点性能、第三者MOD互換は未確認です。日本語は公式パック由来の既存注入エラー全内容だけを照合し、新しい翻訳エラーを許容しません。

試験は `work/inheritance-smoke` の隔離設定・セーブを使い、ゲーム起動は直列に行います。ユーザーの本体設定・セーブを変更せず、過去版ZIP・保存証拠を保持します。ゲーム本体・ゲームDLL・試験セーブ・実行ログ原本は配布ZIPへ含めません。
